# MLOmics: Latent-Fusion Multi-Omics Classifier for Cancer Subtype Prediction

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![CI](https://github.com/deaneeth/multi-omics-cancer-subtype-classifier/actions/workflows/ci.yml/badge.svg?branch=dev)](https://github.com/deaneeth/multi-omics-cancer-subtype-classifier/actions/workflows/ci.yml)

> **⚠️ Academic research prototype. Not for clinical use.**

## Overview

MLOmics is an end-to-end, reproducible multi-omics pipeline for cancer subtype classification on the [MLOmics benchmark dataset](https://figshare.com/articles/dataset/MLOmics_Cancer_Multi-Omics_Database_for_Machine_Learning/28729127).

It evaluates two cancer cohorts with four omics modalities:

- GS-BRCA: 5 subtypes (Basal-like, HER2-enriched, Luminal A, Luminal B, Normal-like) — 671 patients, 15,366 features
- GS-COAD: 4 subtypes (CMS1–CMS4) — 260 patients, 15,200 features
- Modalities: mRNA (5,000 genes), miRNA (366 / 200), DNA methylation (5,000), CNV (5,000)

The project includes early-fusion tree baselines, an intermediate-fusion deep model, and a pathway-aware fusion variant that injects KEGG pathway structure into the mRNA encoder. The Streamlit demo supports both cancers and all three deployed model families, with a Lab Data Converter tab for processing per-modality hospital/lab exports into prediction-ready format.

## Expected Results (5-fold CV, macro F1 ± std)

| Model | GS-BRCA F1 | GS-BRCA AUC | GS-COAD F1 | GS-COAD AUC |
|---|---|---|---|---|
| XGBoost | 0.794 ± 0.047 | 0.970 ± 0.015 | 0.636 ± 0.115 | 0.911 ± 0.051 |
| RandomForest | 0.602 ± 0.083 | 0.971 ± 0.009 | 0.608 ± 0.073 | 0.932 ± 0.021 |
| IntermediateFusion | 0.808 ± 0.050 | 0.963 ± 0.014 | 0.669 ± 0.094 | 0.953 ± 0.008 |
| PathwayAwareFusion | 0.801 ± 0.069 | 0.966 ± 0.017 | 0.738 ± 0.142 | 0.954 ± 0.025 |

**Statistical significance note (Wilcoxon signed-rank, n=5 folds):** The minimum achievable
two-sided p-value with 5 folds is 0.0625. Key pairwise comparisons from
`results/metrics/significance_tests.csv`:

| Comparison | dF1 | p-value | Cohen's d | Interpretation |
|---|---|---|---|---|
| IntFusion vs XGBoost (BRCA) | +0.014 | 0.625 | 0.197 | Not significant; trivial effect |
| IntFusion vs XGBoost (COAD) | +0.033 | 0.625 | 0.324 | Not significant; small effect |
| IntFusion vs RandomForest (BRCA) | +0.206 | 0.0625* | 1.888 | Significant at minimum threshold; very large effect |
| PathwayFusion vs IntFusion (COAD) | +0.069 | 0.3125 | 0.504 | Not significant; medium effect |

\* Minimum achievable p with n=5. Deep fusion models and XGBoost show **comparable performance**
on BRCA; differences are not statistically distinguishable at this sample size.

Full per-fold metrics: `results/metrics/model_comparison.csv`
Pairwise test results: `results/metrics/significance_tests.csv` (generated by `scripts/compute_significance_tests.py`)

**Evaluation protocol note:** All reported metrics use 5-fold cross-validation only. There
is no separate held-out test set. CV F1 estimates carry optimistic bias from the global ANOVA
pre-selection of features and should be interpreted as model-selection performance, not true
generalisation estimates. Replication on an independent cohort is required before drawing
clinical conclusions.

## Setup

All commands must be run from the **repository root**.

### 1. Create and activate the conda environment

```bash
conda create -n mlomics python=3.11 -y
conda activate mlomics
pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cu118
pip install torchvision==0.22.1 --index-url https://download.pytorch.org/whl/cu118
pip install torchaudio --index-url https://download.pytorch.org/whl/cu118
pip install -r requirements.txt
```

### 2. Download the dataset

Follow the instructions in `data/DATA_README.md` to download raw data from Figshare into `data/raw/`. The expected layout is:

```
data/raw/GS-BRCA/Top/GS-BRCA_mRNA_top.csv
data/raw/GS-BRCA/Top/GS-BRCA_miRNA_top.csv
data/raw/GS-BRCA/Top/GS-BRCA_Methy_top.csv
data/raw/GS-BRCA/Top/GS-BRCA_cnv_top.csv
data/raw/GS-COAD/Top/  (same pattern)
```

### 3. Run the full pipeline

> **Reproducibility note:** For full hash-order determinism, prefix all training
> commands with `PYTHONHASHSEED=42` (Linux/macOS) or `$env:PYTHONHASHSEED=42;` (Windows PowerShell).
> The code calls `set_seeds(42)` internally for numpy/torch, but Python's hash seed
> must be set in the environment *before* the interpreter starts.

```bash
# Preprocess and verify (writes data/preprocessed/)
jupyter nbconvert --to notebook --execute notebooks/01_preprocessing.ipynb

# Train baselines (XGBoost + RandomForest, 5-fold CV)
python scripts/train_baselines.py

# Train fusion models
python scripts/train_fusion.py
python scripts/train_pathway_fusion.py

# Explainability and ablations
python scripts/run_explainability.py
python scripts/run_ablations.py

# Compute AUC and significance tests
python scripts/compute_auc.py
python scripts/compute_significance_tests.py

# Generate per-fold ROC curves (BRCA and COAD)
python scripts/generate_roc_curves.py
python scripts/generate_roc_curves_coad.py

# Export demo artifacts
python scripts/prepare_demo_artifacts.py
python scripts/precompute_fusion_attribution.py
python scripts/precompute_latent_space.py

# Generate demo datasets (run once)
python scripts/create_test_datasets.py
python scripts/create_synthetic_patients.py
python scripts/create_demo_patients.py
python scripts/create_lab_patient_files.py

# Launch Streamlit app
streamlit run app/streamlit_app.py
```

## Demo Application

The Streamlit app (`streamlit run app/streamlit_app.py`, ~3,875 lines) provides three tabs:

1. **Prediction** — upload a patient CSV (or batch), get subtype prediction with confidence score, SHAP/IG explainability, pathway attention weights (PathwayAwareFusion), and optional AI-generated research summaries. Live IG computation via Captum as fallback when precomputed attributions are unavailable.

2. **Model Comparison** — side-by-side metrics, ROC curves, per-fold AUC breakdown, confusion matrices, latent space t-SNE, radar charts, training convergence graphs, ablation studies, and biological validation.

3. **Data Converter** — upload per-modality lab CSV files (mRNA, miRNA, methylation, CNV separately), select from **4 input data formats** (already z-scored, log2-transformed, raw counts, or beta values 0–1), auto-map features and miRNA names to training space, get a coverage report per modality, and download a combined prediction-ready CSV. Non-z-scored formats are normalised automatically using robust single-sample z-scoring (median + IQR/1.349).

Pre-built test datasets in `app/test_datasets/` (35 files across 3 directories):
- `test/` (13 files) — real TCGA validation-set patients (ground truth known)
- `synthetic/` (14 files) — statistically generated patients from class distributions
- `demo/` (8 files) — named patients with clinical backstories + lab conversion test files
  - Sarah Mitchell (Luminal A BRCA) and Robert Okonkwo (CMS2 COAD) — prediction-ready
  - Amara Nwosu — four separate lab-format modality files for Data Converter testing

## Known Limitations

1. **Global ANOVA feature pre-selection**: Top-k features were selected using all 931 patients' labels before CV splitting. All F1 scores are slightly inflated compared to a fully independent pipeline. Comparisons between models are still fair.
2. **miRNA artifact on COAD**: Removing miRNA from IntermediateFusion COAD improves F1 by +0.133 (0.669 → 0.802). The model over-weights a noisy miRNA signal on the small COAD dataset.
3. **COAD CMS4**: Only 4 samples. Essentially unlearnable. Some CV folds contain no CMS4 patients.
4. **BRCA miRNA**: 166/366 miRNA columns are entirely NaN (probes not assayed). Filled with 0 after normalization.
5. **Pathway attention**: Weights are nearly uniform (~0.003–0.004) — the model did not learn strong focus on any particular biological pathway.
6. **Single-sample normalization in Data Converter**: Approximate only; cannot correct for batch effects between labs or sequencing platforms.
